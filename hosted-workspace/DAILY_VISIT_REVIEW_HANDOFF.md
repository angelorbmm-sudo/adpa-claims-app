# Daily mitigation visits and drying logs review — 2026-10-13

## Changes
A daily-visit mutation requires explicit sourceChecked confirmation. The form requires a deliberate check of readings, units, equipment changes, professional decisions and linked originals; edits and uploads reset it. Saved visits retain that confirmation alongside their existing actor/time. Older open clients must refresh before submitting. Missing evidence remains a displayed gap, not invented proof or automatic readiness.

Daily visit projections carry an authoritative corrected flag computed from the full job history. A correction hidden by evidence permissions marks the earlier authorized visit superseded without exposing the hidden correction’s facts or sources. Superseded visits are excluded from previous-reading comparisons, correction choices and update drafting. The server also rejects branching a hidden correction chain through a projected company workspace. Original history remains immutable.

Daily update approvals bind the actual visit/visible visit history, source filename/MIME/size/created/category, room name, claim number, audience and selected attachments. Changed context hides prepared copy/download controls until reviewed again. A synchronous preparation key prevents reuse before a React reset effect runs. A corrected visit cannot generate an update through the shared draft helper. If a correction is not visible, users are directed to request its supporting originals from ADPA.

Selecting a correction preserves the prior observation timestamp and precision in the device-local editor. The saved audit timestamp remains separate; users can deliberately correct an incorrectly recorded observation time. Returning to a new visit resets the current time and correction reason.

Duplicate visit/row source IDs are rejected. Zero-valued moisture, RH and temperature remain recorded values. Existing comparisons still require matching test point, location, material, instrument, method and scale and do not conclude drying completion. No psychrometric calculation, duration prescription or restoration certification is added.

Unsaved visits use internal-link/unload protection and offer copy/clear controls outside a disabled form, so paused records do not trap notes. Company and Water Scope Studio callers pass the explicit review confirmation through the existing version/permission checks.
