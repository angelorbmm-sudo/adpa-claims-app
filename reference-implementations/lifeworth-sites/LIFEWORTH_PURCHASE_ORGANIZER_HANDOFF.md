# LifeWorth purchase organizer

Extends the existing private purchase/receipt records. Each receipt line can retain a manually entered return deadline and terms reference, warranty end date and terms/provider reference, separate date confirmations, and an HTTPS manual link. Existing receipt fields, refund reconciliation, inventory quantities, pricing and valuation behavior remain intact. Older records default to empty dates/links and unconfirmed terms when edited.

Open LifeWorth → select a property → Purchase organizer. Search room, item, model or retailer; filter missing purchase records or dates due within 30 days; link a purchase or edit existing details. Confirmed dates use Pacific calendar dates, include today and day 30, and distinguish past recorded dates from unknown terms. Fully returned purchase lines do not contribute to upcoming-date counts. No return eligibility, warranty coverage, live retailer terms or automated notifications are inferred. Original evidence remains represented by references/HTTPS links; no direct file upload was added.

API validation requires real dates, dates on/after purchase, and source terms before a date is confirmed. Existing owner authentication, same-origin protection, optimistic versions and audit persistence are reused. JSON export retains every new field; receipt CSV now includes the new dates, confirmation states, source terms and manual link with existing spreadsheet-formula protection.

Validation: 764 automated tests including backward-compatible defaults, real date and safe URL checks, source requirements, boundary dates, property isolation, returned lines, no mutation during aggregation, API persistence, rejected-update preservation, account isolation and export. TypeScript and production build passed. Managed preview starts but the cloud browser connection is refused; visual/browser interaction QA remains unverified. No sharing/access change, external message, purchase or reminder was made.
