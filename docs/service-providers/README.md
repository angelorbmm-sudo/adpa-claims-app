## Status and purpose

This guide is a proposed product and operating specification. It documents the provider resources and workflows requested by Angelo; it does not certify that these features are implemented or that any provider has been approved or retained.

Each profile explains when the provider enters, its responsibilities, the process in HomeBack, required records, handoffs, completion criteria, and suggested app resources.

## Shared workflow requirements

- Keep LifeWorth central to HomeBack 1, HomeBack 2, and ADPA.
- Use shared property, loss, room, item, material, and document identifiers.
- Preserve separate provider agreements and optional ADPA representation.
- Track work, insurance coverage, and payment separately.
- Keep technical findings attributed to qualified professionals and preserve report limitations.
- Use assignment-specific permissions, area-specific dependencies, and traceable handoff decisions.
